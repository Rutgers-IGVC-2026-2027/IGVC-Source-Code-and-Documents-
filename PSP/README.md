# IGVC Power Systems

This repository contains the power systems processing project.

## Projects

- [Power systems processing](power-systems-processing/): C++ source, tests, and build instructions.

```text
power-systems-processing/

    powerSystemsProcessing.cpp
```

Open the repository root in VS Code to use the shared build and debug settings.
See the [processing README](power-systems-processing/README.md#build-and-run)
for command-line build instructions.
